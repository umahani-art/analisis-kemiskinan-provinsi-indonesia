# Analisis Kemiskinan Antarprovinsi di Indonesia (2025)

## Gambaran Umum

Proyek ini menganalisis variasi indikator kemiskinan antarprovinsi di Indonesia pada tahun 2025 menggunakan R dan R Markdown. Analisis berfokus pada perbandingan kondisi kemiskinan antarwilayah, identifikasi perbedaan tingkat kemiskinan, serta eksplorasi pola hubungan antara indikator yang tersedia dalam dataset.

Proyek ini disusun sebagai bagian dari portofolio analisis data dan riset kebijakan publik, dengan penekanan pada pengolahan data, analisis eksploratif, visualisasi, dan interpretasi temuan.

## Tujuan Analisis

- Membandingkan indikator kemiskinan antarprovinsi di Indonesia.
- Mengidentifikasi provinsi dengan tingkat kemiskinan relatif tinggi dan rendah.
- Mengeksplorasi variasi indikator kemiskinan antarwilayah.
- Menyajikan hasil analisis dalam bentuk visualisasi dan laporan yang dapat ditinjau kembali.

## Metode dan Perangkat Analisis

Analisis dilakukan menggunakan:

- **R** untuk pengolahan dan analisis data.
- **R Markdown** untuk mengintegrasikan kode, narasi, dan hasil analisis dalam satu laporan.
- **Pembersihan dan pemeriksaan data** untuk mempersiapkan dataset sebelum dianalisis.
- **Analisis data eksploratif (Exploratory Data Analysis/EDA)** untuk memahami pola dan variasi data.
- **Visualisasi data** untuk menyampaikan perbandingan indikator kemiskinan antarprovinsi.

## Struktur Repositori

- `Data Kemiskinan Tiap Provinsi.Rmd` — kode dan narasi analisis yang digunakan untuk menghasilkan laporan.
- `Data-Kemiskinan-Tiap-Provinsi.html` — laporan HTML hasil analisis.
- `Jumlah dan Persentase Penduduk Miskin Menurut Provinsi, 2025.xlsx` — dataset yang digunakan dalam analisis.

## Cara Menjalankan Analisis

1. Unduh atau klon repositori ini ke komputer.
2. Buka file R Markdown (`.Rmd`) menggunakan RStudio.
3. Pastikan paket R yang diperlukan oleh kode telah terpasang.
4. Pastikan file Excel tersedia pada lokasi yang sesuai dengan jalur berkas dalam kode.
5. Jalankan proses *Knit* pada RStudio untuk menghasilkan laporan HTML.

## Sumber Data

Proyek ini menggunakan dataset berjudul *Jumlah dan Persentase Penduduk Miskin Menurut Provinsi, 2025*.

Tautan publikasi atau tabel resmi sumber data perlu dicantumkan untuk memudahkan verifikasi, penelusuran sumber, dan pemeriksaan metodologi.

## Batasan Analisis

Analisis ini bersifat deskriptif dan eksploratif. Pola maupun hubungan statistik yang ditemukan tidak dengan sendirinya menunjukkan hubungan sebab-akibat. Interpretasi hasil perlu mempertimbangkan definisi indikator, cakupan data, metode pengumpulan data, dan keterbatasan yang relevan.

Angka dan kesimpulan sebaiknya diverifikasi terhadap sumber data resmi sebelum digunakan sebagai dasar rekomendasi kebijakan atau pengambilan keputusan.
